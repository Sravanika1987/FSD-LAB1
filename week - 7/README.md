Week 7 - Server-Side Rendering

Implement server-side rendering using a template engine and build interactive web pages that handle dynamic data, form input and basic validation.Then open the URL printed in the terminal.

Experiment 1: http://localhost:3002/
Experiment 2: http://localhost:3003/students
Experiments 3 & 4: http://localhost:3004/register
